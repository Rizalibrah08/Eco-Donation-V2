# Eco-Donation — Courier App

Aplikasi kurir: ambil tugas penjemputan, bagikan lokasi selama perjalanan, timbang sampah, lalu tampilkan QR/kode verifikasi untuk dipindai pengguna.

```bash
npm install
npx expo start --port 8082
```

Panduan lengkap, alur sistem, dan akun demo ada di [README utama](../README.md).
Jangan ubah `src/ui/*` langsung (kecuali `theme.ts`). Ubah di `user-app/src/ui`, lalu jalankan `node scripts/sync-ui.js` dari root repo.
