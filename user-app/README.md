# Eco-Donation — User App

Aplikasi warga: setor sampah, lacak kurir secara langsung, pindai QR kurir untuk menyetujui timbangan, donasikan poin, dan kumpulkan lencana.

```bash
npm install
npx expo start
```

Panduan lengkap, alur sistem, dan akun demo ada di [README utama](../README.md).
Komponen di `src/ui` adalah sumber design system; salin ke courier-app dengan `node scripts/sync-ui.js` dari root repo.
